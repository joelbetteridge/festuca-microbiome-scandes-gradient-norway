# The Effect of Environmental Conditions on Fungal/Bacterial Biodiversity

## Overview
This study investigated how temperature and precipitation averages affect 
the biodiversity of bacteria and fungi associated with *Festuca rubra* grass. 
Root samples were collected in a factorial design across 12 sampling sites 
in the Scandes mountains and metagenomically sequenced to identify associated 
fungal and bacterial communities.

## Data
All raw data is stored in `data-raw/`.

- **Tidy_Norway_ASVs...** (.txt) — count data where columns represent 
  environmental samples and rows represent unique Amplicon Sequence Variants 
  (ASVs); values are counts of each ASV per sample.
- **Tidy_Norway_taxonomy...** (.txt) — taxonomic classification for each 
  unique ASV.
- **Tidy_sampleData...** (.txt) — location and environmental metadata for 
  each sample.

## Analysis
The analysis script imports, explores, and tests the relationship between 
fungal/bacterial community composition and precipitation/temperature using:
- Principal Component Analysis (PCA) to visualise community patterns
- Shannon diversity index calculations
- Two-way ANOVA to test significance of environmental effects

Figures generated by this script are included in `figures/` (or `report/`, 
adjust to match your folder).

## Packages used
- `tidyverse` — data import, manipulation, and plotting
- `vegan` — Shannon diversity index
- `factoextra` — PCA visualisation
